# README

这是一个可以进行开发，组装不同种类应用的软件，也许可以组装任何东西。
基本想法：
1. 一个web/desktop app
2. plugin模式，可以menu的plugin，可以工具栏的plugin
3. 总体展示就是3栏，左边栏，右边栏
4. plugin 模式可以先从deepseek harness 模式开始，这是总体插件，主要包括了菜单插件，工具栏插件这些可能是自定义内容
5. 整体工作方式的页面就是总体展示就是3栏，左边栏，中间工作区域，右边栏，
   - 左边是展示项目，目录和对话记录
   - 中间结果展示区域，也可以是浏览器，cavas,terminal和文件编辑内容，比如markdown，或者其他一些定制的可能是Slides等等
   - 左边主要是todo任务，指引已经项目文档
